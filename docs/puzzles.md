# Puzzles

## The Secret Society Passphrase
**Mechanics:** Dialogue trees, item collection
**Puzzle:** Find note in grocery store → Talk to employees about Mr. Arthur → Learn cryptic passphrase → Use passphrase with Mr. Arthur
**Story Impact:** Unlocks museum basement, reveals secret society, advances main mystery

## The Worn ATM Code
**Mechanics:** Visual observation, number sequence logic
**Puzzle:** Examine ATM graffiti showing 4 worn numbers → Find safe requiring 4-digit code → Determine correct sequence from wear patterns
**Story Impact:** Opens safe containing society membership list and ritual instructions

## Medical Records Access
**Mechanics:** Social engineering, timing puzzles
**Puzzle:** Gain Janet's trust → Wait for her break → Access computer terminal → Navigate medical database
**Story Impact:** Reveals pattern of symptoms among society members

## School Lab Break-in
**Mechanics:** Stealth, key finding, chemical knowledge
**Puzzle:** Find janitor's key → Sneak into lab after hours → Identify missing chemicals from inventory → Connect to ritual purposes
**Story Impact:** Discovers what substances are being used in secret ceremonies

## Cave Symbol Translation
**Mechanics:** Pattern matching, historical research
**Puzzle:** Collect symbol rubbings from various locations → Research with Ms. Rodriguez → Translate ancient warnings → Understand cave's true purpose
**Story Impact:** Reveals the danger the society is unleashing

## Sheriff's Evidence Locker
**Mechanics:** Distraction, lock picking mini-game
**Puzzle:** Create distraction for Deputy Collins → Access evidence locker → Find confiscated items that connect to mystery
**Story Impact:** Uncovers physical evidence of supernatural occurrences

## Hospital Security Footage
**Mechanics:** Timing, social manipulation
**Puzzle:** Befriend night nurse → Access security office during shift change → Review footage of strange late-night visitors
**Story Impact:** Identifies society members and their activities
